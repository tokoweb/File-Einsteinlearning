# ELP Storage API

This is an API source code that made by using Lumen. It attends to serve an Storage API for API ELP and it's for commercial use.

# Built With

This project has been built with the following technologies:

- PHP v8

- Lumen Laravel Framework v8

# Install & Usage

First, you can clone the project from your terminal by typing:

```
git clone https://gitlab.com/einstein-course/api.git
cd api && composer install
```

Then you can start your development server with:

```
php artisan serve
```

or

```
php -S localhost:8000 -t public
```
